# Weather-java🌤️

Ein einfaches Java-Programm, das Wetterdaten für eine Stadt ausgibt. Unterstützt die Anzeige von Temperatur, Windgeschwindigkeit und Wetterbeschreibung.

## Anforderungen
- Java Development Kit (JDK) 21 oder höher.

## Geplante Erweiterungen
- Unterstützung für zusätzliche Wetterdaten wie Luftfeuchtigkeit und Sonnenaufgang/-untergang.
